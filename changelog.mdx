## 2026-07-29

- Added curated `/llms.txt`, `/llm.txt` compatibility file, agent manifest,
  agent handoff contract, LinkedIn/Reddit agent workflows, webhook consumer
  workflow, AI contextual actions, and automated agent-doc drift validation.
- Added owner-scoped `/v1/reddit` registration, status, lifecycle, post, batch, and delivery APIs.
- Added registration/revision-scoped Reddit provenance, two-stage relevance, cross-day deduplication, immutable daily batches, and signed webhooks.
- Added extension-only Reddit public author context with a seven-day cache and no Parallel or real-world identity resolution.
- Added Akhil-persona Reddit reply drafts for Barada; drafts are advisory and never posted automatically.
- Added database-managed Reddit extension grants and persona assignments without creating a Barada registration or task.
- Updated the existing direct ZIP/unpacked connector to `0.6.0` while preserving extension ID `memidhnoiniadgfomefhmcahjcekkddd`.
- Added unit, API, migration, HTTP integration, extension contract, and production real-Chrome smoke verification.

The Reddit public event version is `reddit.relevant_posts.daily.v1`.

## 2026-07-28

- Added the FastAPI `/v1` public control plane with generated owner API keys.
- Added multi-registration CRUD, lifecycle actions, status, batch polling, and delivery replay.
- Added immutable daily relevant-post batches and signed retryable webhooks.
- Added requirement revisions and registration-scoped cross-day deduplication.
- Added DB-backed shared extension grants for Akhil, Deep, and Barada.
- Added Barada provisioning with Akhil as the effective LinkedIn comment persona.
- Added correlation IDs, JSON event logs, durable run events, and webhook attempts.
- Updated the existing unpacked connector to `0.5.7` so the same installed Chrome profile propagates run request IDs without re-pairing.
- Added unit, API, migration, integration, extension E2E, log-verification, and dashboard coverage.
- Added generated OpenAPI 3.1 and the Mintlify documentation project.

The public event version remains `linkedin.relevant_posts.daily.v1`.
