## 2026-08-06 - API 1.3.0

- Added owner and credential discovery through `/v1/me` and paginated project
  discovery through `/v1/projects`.
- Standardized current LinkedIn and Reddit post retrieval with normalized score,
  status, stage, cursor, and current-revision behavior.
- Added idempotent external draft intake for both platforms. Drafts enter human
  review as revisions and never approve or publish through the public API.
- Added `discovery_only` and `draft` registration modes while retaining
  `draft_enabled` compatibility.
- Projected active external drafts into dashboard review and preserved their
  provenance when final edited text enters either durable publishing queue.
- Documented exact raw-body webhook verification with a five-minute tolerance.
- Consolidated the integration contract into `/agent`, `/agent.md`, `/llms.txt`,
  and OpenAPI, with schema-validated examples for all public list surfaces.

## 2026-07-30

- Added LinkedIn compiler-native registration creation through one detailed
  `use_case`, using the official TypeScript OpenAI Agents SDK and validated
  structured output.
- Added immutable plan revisions with exactly ten search plans, post and
  author/ICP rubrics, rendered prompts, explicit hard-filter provenance,
  normalized weights, thresholds, assumptions, and integrity hashes.
- Added plan read, regenerate, and validated advanced-override endpoints.
- Added correlated ten-run cycles for activation, cadence, and manual runs while
  preserving the existing real-extension protocol and global single-run rule.
- Limited Parallel enrichment to first-pass matches and expanded normalized
  public author/company evidence with schema-versioned caching.
- Made final scoring deterministic from persisted components and represented
  missing author evidence as neutral `UNKNOWN` with reduced coverage.
- Enabled Barada for live compilation and Akhil/Deep for shadow plans, with no
  shadow changes to their current behavior.
- Updated agent, OpenAPI, Mintlify, logging, CI, and real-extension smoke
  contracts for compiler-aware operation.
- Hardened compiler version `linkedin-plan-v2` so clipped, unbalanced,
  overlong, or unsupported LinkedIn search syntax is rejected before
  activation and retried without creating tasks.

The LinkedIn event remains `linkedin.relevant_posts.daily.v1`.
