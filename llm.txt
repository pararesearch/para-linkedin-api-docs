# PARA Social Research API agent index

> Compatibility entrypoint for agents that request `llm.txt` instead of the standard `llms.txt`.

Use the canonical agent index:

- [llms.txt](https://para-linkedin-api.mintlify.site/llms.txt): Curated directives and documentation links.
- [Agent quickstart](https://para-linkedin-api.mintlify.site/agents/quickstart.md): Bootstrap and execution policy.
- [Agent manifest](https://para-linkedin-api.mintlify.site/agent-manifest.json): Machine-readable capabilities and safety rules.
- [Live OpenAPI](https://para-linkedin-api.onrender.com/openapi.json): Canonical API and webhook contract.

Do not place API keys, webhook secrets, temporary passwords, or authorization
headers in prompts, logs, URLs, checkpoints, or artifacts.
