The dashboard continues to authenticate with its existing JWT session.

## First login

1. Sign in with the temporary password returned during provisioning.
2. The dashboard routes directly to the required password-change form.
3. Set a permanent password.
4. Open the LinkedIn workspace.

## Registrations

The registration selector allows a user to create and switch between several
research streams. The LinkedIn editor accepts a detailed use case, optional
legacy seeds and constraints, scheduling, score thresholds, result limit,
webhook URL, and draft settings. Compiled registrations expose compilation
state, the active plan revision, all ten per-query states, and readable plan
details.

Lifecycle controls support activate, pause, archive, restore, and run now. The results area is filtered to the selected registration and shows batch status, final posts, scoring details, author enrichment, and drafts.

For Barada, the effective draft persona is shown as Akhil while the registration editor remains Barada scoped. Akhil and Deep's preexisting dashboard and digest behavior continue through their primary registrations.
